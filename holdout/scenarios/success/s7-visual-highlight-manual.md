# 人工验收：命中分层的视觉编码

**判卷机判不了的**：颜色、线型、图例、拖拽——这些只能人看。

请打开 `python -m graphkb.cli serve`，铺上 `kb-small` 那类图，问一句「张三在哪工作」，
逐条核对：

- [ ] 锚点（`张三`）是**实线粗环**，引用点（`北京中关村` 一类）是**虚线细环**
- [ ] 路径中间节点与锚点/引用点**颜色不同**（多轮命中有 `¹ ² ³` 角标）
- [ ] 右下角图例说明了每一档的含义，而不是只有颜色没有解释
- [ ] 人为改过的实体带 `✎` 与紫色底晕（M4 溯源），且详情面板显示来源文档
- [ ] 答案面板可以拖动，不挡图
- [ ] 「没有命中」时给出的是明确提示，而不是一片空白
