# Expectations: slice-4-graph-edit

> 用户语言，定义"什么算完成 / 什么算失败 / 边界怎么处理"。
> 可执行的具体场景（含断言）在 `holdout/scenarios/slice-4-graph-edit/`，构建时代理不可见。

## Success Scenarios

| 场景 | 期望行为 |
|------|----------|
| 打开页面，图里有实体/关系 | 页面渲染出整张图：实体节点 + 关系边，能看清实体名与关系 |
| 编辑一个实体的描述/类型 | 改动落库，重新读图该实体描述/类型已更新 |
| 删除一个实体 | 实体从图里消失（其关系一并处理，不残留孤儿边） |
| 合并两个实体 | 复用合并能力，源删除、关系转移到目标 |
| 新建一个实体/关系 | 实体/关系出现在图里 |

## Failure Scenarios

| 场景 | 期望行为 |
|------|----------|
| 编辑操作后重新读图，改动没生效 | 系统必须显式失败/报告，绝不"界面假改" |
| 页面请求图数据失败（后端没起来/图空） | 前端得体提示（不白屏崩溃），后端 API 返回明确错误 |

## Boundary Scenarios

| 场景 | 期望行为 |
|------|----------|
| 编辑一个**不存在**的实体名 | 后端得体报错（明确指出不存在），不改动图 |
| 删除一个**不存在**的关系 | 得体报错或 no-op，不崩溃 |
| 图为空（无实体） | 页面正常显示"空图"提示，不崩溃 |
