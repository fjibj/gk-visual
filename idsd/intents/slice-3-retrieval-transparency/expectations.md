# Expectations: slice-3-retrieval-transparency

> 用户语言，定义"什么算完成 / 什么算失败 / 边界怎么处理"。
> 可执行的具体场景（含断言）在 `holdout/scenarios/slice-3-retrieval-transparency/`，构建时代理不可见。

## Success Scenarios

| 场景 | 期望行为 |
|------|----------|
| 检索命中若干实体/关系后渲染 | 渲染输出列出这些命中实体/关系（名字 + 分数），不是只给一句黑盒答案 |
| 检查命中项的分数 | 每个命中实体/关系都有余弦分数（0~1 之间）；确有原因的才给分数 |
| 看检索路径解释 | 能看出"高层关键词 → 低层实体 → 关系 → 块"的链条（dual-level 可见） |

## Failure Scenarios

| 场景 | 期望行为 |
|------|----------|
| 逐项分数拿不到（向量库查询异常/无结果） | 该命中项如实标注"无分数"，不编造一个数字 |
| trace 空（未命中） | 渲染如实显示"未命中"，不画任何假命中路径 |

## Boundary Scenarios

| 场景 | 期望行为 |
|------|----------|
| 命中实体在向量库查不到分数（如注入图未向量化） | 该实体标注"无分数"，渲染不崩溃 |
| 分数极低（接近 0）但仍在命中列表里 | 照实显示低分，不隐藏、不夸大 |
