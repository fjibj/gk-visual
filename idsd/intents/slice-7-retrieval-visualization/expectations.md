# Expectations: slice-7-retrieval-visualization

> 用户语言，定义「什么算完成 / 什么算失败 / 边界怎么处理」。
> 可执行的具体场景（含断言）在 `holdout/scenarios/slice-7-retrieval-visualization/`，构建时代理不可见。

## Success Scenarios

| 场景 | 期望行为 |
|------|----------|
| 检索框输入问题提交 | 返回答案 + trace，图上命中实体/关系高亮 |
| 命中实体/关系高亮 | 命中项按分数着色，未命中项淡化 |
| 连续多轮检索 | 图上叠加多轮路径，当前轮最深、历史逐轮变浅 |

## Failure Scenarios

| 场景 | 期望行为 |
|------|----------|
| 检索有命中但图上不显示高亮 | 系统必须显式失败/报告，绝不「返回了路径却画不出来」 |
| 多轮后颜色无区分 | 系统必须显式失败/报告，绝不「假装演进了」 |

## Boundary Scenarios

| 场景 | 期望行为 |
|------|----------|
| 检索未命中（trace 空） | 得体提示「未命中」，图上不高亮任何项，不崩溃 |
| 后端没起来/检索 API 报错 | 前端得体提示，不白屏 |
| 命中的实体已不在当前图（被编辑删除） | 高亮仅作用于现存节点/边，不崩溃 |
