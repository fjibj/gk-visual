## 验收轮次修订（2026-08-30，Step 8 进行中）

用户复验时报：**多轮颜色演进看不出来**——搜「周杰伦在哪里开演唱会」后，上一轮的张三那批节点「不是浅粉，还是红色」。

查（浏览器 evaluate 读 `hitAge` + `renderedStyle`）：轮次记录与 age 计算**逻辑正确**（张三节点确实拿到 age=1），错在色阶本身：旧第二档 `#e05a6a` 与第一档 `#c81e2e` 色相几乎相同（仅亮度差 12%），在小尺寸细环上看着都是「红」。

修（纯展示层，未动检索）：
1. **拉开色阶**：`#c81e2e → #ef8a96 → #f7c3ca → #fbe2e6`（第一→第二档从「红 vs 红」变成「深红 vs 浅粉」）。
2. **多维编码**：旧轮次同时变细（边框 5→2.5px）、变小（节点 40→34）、变淡（opacity 1→0.72）——不依赖单一颜色维度。
3. **右下角图例**：本轮命中 / 上一轮 / 更早 / 未命中，带色块，无检索时隐藏。
4. **防陈旧前端**：`server.py` 加中间件，对 `*.html` / `/` / `/api/*` 下发 `Cache-Control: no-cache`——之前改完前端必须 Ctrl+F5 才能看到新构建（本次自查也被这个坑到：浏览器拿着 8-18 的旧 JS 不放）。

验证：浏览器连问三题（张三 / 字节跳动 / 周杰伦），读得 age=0 为 rgb(200,30,46)+5px+40、age=1 为 rgb(239,138,150)+2.5px+34+opacity 0.72，边同步；李雷/腾讯/深圳 仍为未命中淡化；pytest 41 passed。
